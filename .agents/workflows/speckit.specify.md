# Workflow: Speckit Specify

Guía para redactar un nuevo `spec.md` para un paquete de funcionalidad:
1. Usar la plantilla `.specify/templates/spec-template.md`.
2. Definir el QUÉ con precisión.
3. Listar requisitos funcionales (RF-XX) y no funcionales (RNF-XX).
4. Establecer criterios de aceptación verificables mediante tests automatizados.
