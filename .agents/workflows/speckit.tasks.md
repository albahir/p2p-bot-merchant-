# Workflow: Speckit Tasks

Guía para desglosar el plan en tareas atómicas (`tasks.md`):
1. Usar la plantilla `.specify/templates/tasks-template.md`.
2. Asignar identificadores secuenciales a cada tarea (ej. T-001.1).
3. Cada tarea debe tener un archivo concreto asignado.
4. Incluir tareas explícitas de tests (unitarios, integración).
