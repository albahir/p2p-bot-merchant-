# Workflow: Speckit Implement

Guía para la implementación de código bajo TDD:
1. Tomar la siguiente tarea pendiente en `tasks.md`.
2. Escribir primero el test en `tests/` que verifique la condición requerida (rojo).
3. Implementar el código en `src/` hasta que el test pase (verde).
4. Refactorizar y verificar con `ruff check .` y `mypy src/`.
5. Marcar la casilla `[x]` en `tasks.md`.
