# Workflow: Speckit Plan

Guía para diseñar la arquitectura técnica en `plan.md`:
1. Usar la plantilla `.specify/templates/plan-template.md`.
2. Definir el stack tecnológico y dependencias.
3. Especificar módulos a modificar o crear en `src/`.
4. Documentar decisiones de diseño (ADRs) y dependencias de otros paquetes.
